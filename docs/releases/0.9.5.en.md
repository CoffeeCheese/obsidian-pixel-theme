# Pixel 0.9.5

## Highlights

- **A complete Project Manager settings flow** docks the action bar to the modal edge, keeping Cancel and Save clearly available while long forms scroll without the previous footer gap.
- **Consistent, lighter custom fields** align text inputs, type dropdowns, and option rows to one control geometry while preventing selected values from being clipped.
- **Project Manager Insights integration** gives the read-only assignee workload view a dedicated Pixel treatment across filters, metrics, assignee summaries, and task details.

## Changes

- Split Project Manager project settings into an independently scrolling content area and a docked footer, removing the space below its actions.
- Unified the height, radius, edge, and focus feedback of project names, member fields, custom-field names, type selectors, and option inputs.
- Reduced the visual weight of custom-field option rows while preserving their editing hierarchy and visible keyboard focus.
- Fixed vertically clipped labels in Project Manager native dropdowns and reserved stable room for their disclosure arrows.
- Added ledger-inspired colors, compact lists, filter controls, metric cards, and state feedback for Project Manager Insights.
- Updated both READMEs and the compatibility notes to list Project Manager Insights as an explicitly supported community plugin.

## Compatibility

- Minimum Obsidian version: `1.12.0`
- Priority platforms: desktop and iOS
- Project Manager and Project Manager Insights styling primarily targets their desktop plugin interfaces.
- This visual PATCH release does not change theme settings or user data.
