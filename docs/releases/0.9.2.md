# Pixel 0.9.2

## 更新亮点

- 重新整理 Preferences 的交互层级：搜索框、核心插件操作按钮、开关与左侧导航现在共享更稳定的像素化几何、对齐和反馈节奏。
- 修正 macOS 桌面端顶栏、功能区与圆角窗口交界处的底色和接缝，让顶部工作区保持连续、干净的纸面观感。
- 优化核心插件搜索体验：聚焦时显示克制的扫描轨道动效，空闲时不再残留装饰线条，并完整遵循减少动态效果设置。

## 更新内容

- 将 Preferences 搜索框改为单层细边缘；聚焦时使用内收式青色状态提示，移除未聚焦状态下多余的外框和左侧粗线。
- 统一核心插件页的设置、附加操作与启用开关布局，修复按钮偏移和滑块超出轨道的问题，并保持键盘焦点与按压反馈。
- 为 Preferences 左侧选项加入稳定的浅青悬停槽位，移入、移出时不发生位移，当前选中项仍保持更深层级。
- 调整 macOS 顶部控制区的背景映射、深色模式圆角与功能区接缝，减少窗口边缘的突兀色块。
- 移除生成 CSS 总体积的 1 MiB 构建门禁；内嵌字体的 0.9 MiB 预算、自包含资源校验和发布资产检查继续保留。

## 兼容性

- 最低 Obsidian 版本：`1.12.0`
- 已验证平台：桌面端；iOS 延用 `0.9.1` 的验证结果
- 未验证平台：Android
- 社区插件：遵循官方 Obsidian CSS 变量的插件可自然继承样式，但不承诺单个插件兼容性。

## 已知问题

- Android 尚未完成实体设备验证，不属于当前支持声明。
- `0.9.x` 仍处于公开公测阶段，视觉细节与覆盖范围会根据社区反馈继续调整。

## 发布验收

- 自动化测试：Pass
- 桌面人工检查：Pass
- iOS 人工检查：Not required
- Android：Unverified
