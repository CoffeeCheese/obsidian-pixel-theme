# Pixel 0.9.6

## Highlights

- **Project Manager tags now match Pixel** with compact capsules that keep labels, dots, and removal actions clear while eliminating the oversized controls and doubled edges of the previous presentation.

## Changes

- Reused Pixel's theme variables for the background, edge, text, radius, and weight of tags in the Project Manager task editor.
- Reduced tags to a compact height and added safe truncation for long labels.
- Reset the tag removal button where global button styling previously introduced incorrect height, borders, shadows, and corner geometry.
- Added consistent hover, keyboard-focus, and pressed feedback for tags and their removal actions.
- Added a Project Manager tag styling contract test to prevent later control rules from regressing the layout.

## Compatibility

- Minimum Obsidian version: `1.12.0`
- Priority platforms: desktop and iOS
- This refinement targets the Project Manager desktop task editor.
- This visual PATCH release does not change theme settings or user data.

- No known issues.
