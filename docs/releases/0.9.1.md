# Pixel 0.9.1

## 更新亮点

- 针对 Obsidian 官方主题目录的自动扫描完成兼容性优化，安装说明、英文文档和主题包体积均符合更清晰的社区交付标准。
- 修复笔记属性区与正文不对齐、属性类型图标被裁切的问题，让属性、标题与正文重新共享同一条阅读轴。
- 移动端左右抽屉恢复完全由 Obsidian 原生行为控制，避免打开抽屉时正文被额外移出屏幕。

## 更新内容

- 将英文 README 作为仓库入口，并保留顶部中英文切换；补充明确的安装、使用与自定义说明。
- 移除 Release CSS 中内嵌的 JetBrains Mono，代码字体改为继承 Obsidian 配置与系统等宽字体，将生成的 `theme.css` 控制在 1 MiB 以内。
- 移除 `:has()`、`clip-path` 与不必要的自定义元素选择器，减少官方扫描警告与高成本选择器。
- 重置文档属性容器的原生横向位移，并移除属性图标的零宽占位行，恢复完整的文本、日期和标签图标。
- 更新版本与移动端契约测试，使测试随当前 manifest 自动验证，而不再绑定单一历史版本。

## 兼容性

- 最低 Obsidian 版本：`1.12.0`
- 已验证平台：桌面端、iOS
- 未验证平台：Android
- 社区插件：遵循官方 Obsidian CSS 变量的插件可自然继承样式，但不承诺单个插件兼容性。

## 已知问题

- Android 尚未完成实体设备验证，不属于当前支持声明。
- `0.9.x` 仍处于公开公测阶段，视觉细节与覆盖范围会根据社区反馈继续调整。

## 发布验收

- 自动化测试：Pass
- 桌面人工检查：Pass
- iOS 人工检查：Pass
- Android：Unverified
