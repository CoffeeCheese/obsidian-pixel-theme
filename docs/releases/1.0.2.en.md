# Pixel 1.0.2

## Highlights

- Redesigned desktop code panels with square language nameplates in Reading view and a separately visible copy button.
- Fixed system overlay scrollbars covering the last line of horizontally scrolling code.
- Improved syntax readability in Light/Dark modes and PDF exports.

## Changes

- Language nameplates use a paper fill, amber outline, and hard pixel shadow. Long identifiers wrap; blocks without a language have no nameplate.
- Code scrolls horizontally without moving the copy button out of view. Space below the code keeps overlay scrollbars clear of the text.
- Unified code borders, line spacing, and active-line feedback in Live Preview and Source mode while preserving native editing, selection, and copy interactions.
- Narrowed panel styling to preserve native layouts for nested code, bare preformatted text, and special rendered content.
- PDF exports use syntax colors suited to paper, wrap long lines, and retain code across pages. Nameplates, copy buttons, and screen scrollbar spacing are excluded from print.

Full commit range: [1.0.1 → 1.0.2](https://github.com/CoffeeCheese/obsidian-pixel-theme/compare/1.0.1...1.0.2).

## Compatibility

- Minimum Obsidian version: `1.12.0`, unchanged.
- Verified desktop Light/Dark modes, narrow windows, Reading view, and editing modes; no migration is required.
- Existing mobile layouts are preserved. This patch was not separately tested on an iOS device.

## Known issues

- Nameplates depend on Obsidian's language identifier and a monospace font. Identifiers normalized to no language and code blocks with additional custom classes do not receive nameplates.
- Full compatibility with third-party custom renderers is not guaranteed.

## Release validation

- Automated tests: Pass
- Desktop manual check: Pass
- iOS manual check: Not required

All 205 automated tests passed. Long-code checks covered Light/Dark modes, wide/narrow windows, two scrollbar modes, and three content variants: 24 live checks. Text positions in the pagination fixtures match the exports from before the redesign.
