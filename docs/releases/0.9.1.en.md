# Pixel 0.9.1

## Highlights

- Completed compatibility refinements for the Obsidian community-directory scan, with clearer installation guidance, an English repository entry point, and a smaller release package.
- Fixed the in-note property sheet alignment and clipped property-type icons so properties, titles, and note content share one readable axis again.
- Returned mobile drawer positioning fully to Obsidian's native behavior, preventing the note from being shifted off-screen when either drawer opens.

## Changes

- Made the English README the repository entry point while keeping the bilingual switch, and added explicit installation, usage, and customization guidance.
- Removed embedded JetBrains Mono from release CSS; code now inherits Obsidian's configured and system monospace stack, keeping generated `theme.css` below 1 MiB.
- Removed `:has()`, `clip-path`, and unnecessary custom-element selectors to reduce community-scan warnings and expensive selector matching.
- Reset the native horizontal property-sheet offset and removed the zero-width icon spacer that pushed text, date, and tag glyphs into a clipped grid row.
- Made version and mobile contracts follow the current manifest instead of coupling tests to a single historical release.

## Compatibility

- Minimum Obsidian version: `1.12.0`
- Verified platforms: desktop and iOS
- Unverified platform: Android
- Community plugins: plugins using official Obsidian CSS variables should inherit the theme naturally, but individual plugin compatibility is not guaranteed.

## Known issues

- Android has not completed physical-device validation and remains outside the current support claim.
- `0.9.x` remains a public beta series; visual details and surface coverage will continue to evolve from community feedback.
