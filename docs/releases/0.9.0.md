# Pixel 0.9.0

## 更新亮点

- Pixel 首次以公开公测版本进入 Obsidian 主题社区，覆盖桌面端与 iOS 的 Light / Dark 工作流。
- 建立由纯 SemVer tag 驱动的可复现发布链路，后续版本可由 Obsidian 自动发现和升级。
- 为 Markdown、文件导航、属性、Bases、Canvas、Graph 与 PDF 提供统一的纸张像素视觉语言。

## 更新内容

- 完成桌面连续工作区、原生双抽屉 iOS 布局以及键盘、触摸和缩放适配。
- 内嵌 Fusion Pixel 与 JetBrains Mono 字体，主题运行时不请求远程字体或图片。
- 增加浅色、深色、减少动态、强制颜色和增强对比度适配。
- Release 仅交付 `theme.css` 与 `manifest.json`，并生成 GitHub 构建来源证明。

## 兼容性

- 最低 Obsidian 版本：`1.12.0`
- 发布验证范围：桌面端、iOS
- 未验证平台：Android
- 社区插件：遵循官方 Obsidian CSS 变量的插件可自然继承样式，但不承诺单个插件兼容性。

## 已知问题

- Android 尚未完成实体设备验证，不属于当前支持声明。
- `0.9.x` 属于公开公测阶段，视觉细节和覆盖面仍会根据反馈持续调整。

## 发布验收

- 自动化测试：Pass
- 桌面人工检查：Pass
- iOS 人工检查：Pass
- Android：Unverified
