# Pixel 0.9.7

## 更新亮点

- **文件操作定位更轻、更准确**：在文件列表中右键非当前文件时，原先厚重的绿色外框被替换为紧凑的青色像素游标，不再与当前文件状态争夺视觉焦点。
- **Project Manager 新增操作清晰可见**：设置页的“add member”和“add status”按钮现在拥有稳定的文字对比度，并以克制的 Pixel 动效反馈悬停、按下与键盘聚焦状态。

## 更新内容

- 将文件树临时右键目标收敛为浅色背景、细边框和内嵌青色竖轨，同时保留高对比度模式下的系统颜色提示。
- 修复 Project Manager CTA 按钮因浅色主题表面覆盖原生背景后仍保留白色文字，导致内容难以辨认的问题。
- 重新设计 Project Manager 新增按钮的静止、悬停、按下和键盘焦点状态；青色竖轨仅在悬停时从中心展开，并完整覆盖按钮左边缘。
- 为减少动态效果偏好关闭按钮过渡动画，并新增文件导航与 Project Manager 设置按钮的契约测试，防止样式回退。

## 兼容性

- 最低 Obsidian 版本：`1.12.0`
- 优先适配平台：桌面端、iOS
- 本次修复针对桌面端文件列表及 Project Manager `1.8.0` 设置界面。
- 本次为视觉修复型 PATCH 版本，不改变主题配置或用户数据。
