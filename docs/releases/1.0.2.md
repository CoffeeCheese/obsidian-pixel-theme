# Pixel 1.0.2

## 更新亮点

- 重新设计桌面代码面板，阅读模式新增方角语言铭牌，复制按钮保持独立可见。
- 修复长代码横向滚动时，系统浮动滚动条遮挡最后一行的问题。
- 改善浅色、深色及 PDF 中的代码语法层次和可读性。

## 更新内容

- 语言铭牌采用纸面底色、琥珀描边与像素硬阴影，长语言名自动换行，无语言代码不显示铭牌。
- 代码独立横向滚动，复制按钮不随代码移出视野；底部预留滚动空间，避免浮动滚动条覆盖文字。
- 统一实时预览与源码模式的代码边框、行距和活动行反馈，保留原生编辑、选择及复制交互。
- 收窄面板样式作用域，保留嵌套代码、裸预格式文本与特殊渲染内容的原生布局。
- PDF 使用适合纸面的语法颜色，长行自动换行、多页代码完整输出；铭牌、复制按钮和屏幕滚动留白不进入打印。

完整提交范围：[1.0.1 → 1.0.2](https://github.com/CoffeeCheese/obsidian-pixel-theme/compare/1.0.1...1.0.2)。

## 兼容性

- 最低 Obsidian 版本：`1.12.0`，保持不变。
- 桌面浅色、深色、窄窗口、阅读与编辑模式已验证；无需迁移。
- 保留现有移动端布局，本补丁未单独进行 iOS 真机测试。

## 已知问题

- 铭牌依赖 Obsidian 提供的语言标识与等宽字体；被原生渲染器归为无语言的标识、附加自定义 class 的代码块不显示铭牌。
- 第三方自定义渲染器的兼容性不作完整保证。

## 发布验收

- 自动化测试： Pass
- 桌面人工检查： Pass
- iOS 人工检查： Not required

205 项自动化测试通过；长代码覆盖浅色/深色、宽/窄窗口、两种滚动条和三种内容形态，共 24 组实机检查。实际导出 6 份 PDF，确认铭牌隐藏、长代码完整、210 行跨页代码无缺失或重复，且跨页样例的文字位置与改版前一致。
