# Pixel 0.9.3

## 更新亮点

- **Pixel Boy 新标签页**：把空白页变成一台真正属于 Pixel 的掌上游戏机；点阵屏、十字键、A / B 键与 Select / Start 共同构成完整的 Game Boy 视觉，同时保留创建文件、打开文件和关闭标签页等原生操作。
- **Claudian 原生融合**：为助手面板、输入区、上下文标签与弹出菜单建立专属 Pixel 布局，让 AI 协作自然融入桌面工作区。
- **更统一的系统控件**：设置页卡片、圆形主题色选色器、搜索框边缘状态、行内标签与紧凑状态栏共享同一套像素化视觉语言。

## 更新内容

- 新增适配浅色、深色与窄屏布局的 Pixel Boy 新标签页，并保持所有装饰元素不可交互、不干扰键盘导航。
- 重构 Claudian 面板与编辑器布局，修复输入区菜单越界裁切，优化上下文标签、标签页和偏好设置的状态表达。
- 统一 Obsidian 设置页卡片样式，移除多余原生分隔线，并将主题色选色器调整为带清晰边界的圆形色井。
- 重新平衡右侧停靠区与全局状态栏，使同步、字数、反向链接等状态信息更紧凑且不挤压正文。
- 优化搜索输入框在默认、悬停、聚焦和无障碍模式下的边缘层级。
- 改进行内标签及编辑器标签片段的胶囊式呈现，保持阅读模式与实时预览一致。
- 更新中英文 README，以隐私安全的特写截图展示主题特色与桌面 / iOS 优先适配方向。
