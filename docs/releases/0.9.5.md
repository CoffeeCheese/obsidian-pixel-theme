# Pixel 0.9.5

## 更新亮点

- **更完整的 Project Manager 设置体验**：项目设置弹窗的操作栏现在紧贴底部，滚动长表单时 Cancel 与 Save 始终清晰可用，不再出现影响连续性的底部缝隙。
- **统一而轻盈的自定义字段**：输入框、类型下拉框与选项行采用一致的尺寸和边框层级，长内容不再被控件裁切，密集设置也更易浏览。
- **Project Manager Insights 视觉适配**：为只读的负责人工作量统计视图补充 Pixel 专项样式，让筛选、指标、人员汇总和任务明细自然融入主题。

## 更新内容

- 将 Project Manager 项目设置弹窗整理为独立滚动内容区与固定底部操作栏，并修复操作栏下方的空隙。
- 统一项目名称、成员、Custom fields 名称、类型选择器与普通选项输入框的高度、圆角、边框和聚焦反馈。
- 降低 Custom fields 选项行的视觉重量，同时保留清晰的编辑层级和可辨识的键盘焦点。
- 修复 Project Manager 原生下拉框文字被垂直裁切的问题，并为箭头区域保留稳定空间。
- 新增 Project Manager Insights 的台账式配色、紧凑列表、筛选控件、指标卡片和状态反馈适配。
- 更新中英文 README 与兼容性说明，明确 Project Manager Insights 为专项支持的社区插件。

## 兼容性

- 最低 Obsidian 版本：`1.12.0`
- 优先适配平台：桌面端、iOS
- Project Manager 与 Project Manager Insights 专项样式主要针对桌面端插件界面。
- 本次为视觉修复型 PATCH 版本，不改变主题配置或用户数据。
