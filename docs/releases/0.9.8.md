# Pixel 0.9.8

## 更新亮点

- **Markdown 细节更稳定、更易辨认**：改善图片快速滚动、任务完成反馈和围栏代码块的视觉识别，并新增适合页首展示的横幅图片格式。
- **输入与文档体验更清晰**：Templater 日期输入框拥有更轻、更明确的交互边界，README 的版本摘要、安装说明和详情内容也更便于直接阅读。

## 更新内容

- 修复 Live Preview 中包含对齐图片的长文档在快速滚动时可能出现大片空白的问题，并保持图片原有尺寸与对齐结果。
- 新增 `pixel-banner` 图片格式，可通过 `![[图片.png|pixel-banner]]` 展示全宽裁切横幅。
- 优化任务复选框的完成和按压反馈，切换状态时不改变复选框尺寸或任务行布局，并遵循减少动态效果偏好。
- 为围栏代码块增加青色 Pixel 顶部状态牌；Live Preview 显示真实语言名称，Reading 显示统一的 `CODE` 标识，原生复制按钮保持可用。
- 优化 Templater 日期输入框的静止、悬停、聚焦、减少动态效果和强制颜色状态。
- 重新梳理 README 的近期版本摘要与安装说明，并让详情内容默认展开。

## 兼容性

- 最低 Obsidian 版本：`1.12.0`
- 优先适配平台：桌面端、iOS
- 本次为 Markdown、Templater 与文档细节优化，不改变主题设置或用户数据。
