# Pixel 1.0.1

## Highlights

- Fixed plugin toggle thumbs extending outside their tracks in Preferences.
- Fixed the search clear button's hover background covering the search field border.

## Changes

- Moved shared control scope roots above `body`, restoring native-surface selectors while retaining the Claudian content boundary. This prevents Pixel thumb positioning from combining with native translation in plugin lists.
- Removed the filled search-clear background in idle, hover, and pressed states. Native icons, click targets, color feedback, and keyboard focus indicators remain intact.
- Added live regression checks for settings toggles and Chromium search-clear interaction states, including detached Preferences windows and Light/Dark modes.

Full commit range: [1.0.0 → 1.0.1](https://github.com/CoffeeCheese/obsidian-pixel-theme/compare/1.0.0...1.0.1).

## Compatibility

- Minimum Obsidian version: `1.12.0`, unchanged.
- Supported targets remain desktop and iOS; no migration is required.
- Claudian's native content boundary is preserved and its runtime checks pass.

## Known issues

- No new blocking issues found in desktop verification or independent review.
- Mobile CSS toggle states were checked on desktop; this patch was not separately tested on an iOS device.

## Release validation

- Automated tests: Pass
- Desktop manual check: Pass
- iOS manual check: Not required

This narrow settings-control patch received desktop visual and interaction checks. It adds no mobile layout or compatibility changes; mobile CSS toggle states were also checked.
