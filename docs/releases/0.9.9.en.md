# Pixel 0.9.9

## Highlights

- **More stable interaction feedback.** Buttons have clearer hover, press, and persistent active states, with consistent reduced-motion behavior. This release fixes doubled primary-button outlines and jitter in the PDF find controls.
- **More comfortable reading in long notes and narrow panes.** Tabs, properties, quotes, code, tables, embeds, and task lists handle constrained space more consistently. Completed tasks retain their strikethrough without striking through unfinished subtasks.
- **Clearer core surfaces.** Settings, search, dark floating surfaces, Bases, Canvas, and print output receive visual refinements while retaining Pixel's identity and native interactions.

## Changes

- **Buttons and motion:** Retained sliding, press, and rebound feedback while removing text scaling on press. Clarified primary and destructive actions and removed inner highlights that caused doubled primary-button outlines. Persistently active panel buttons show a cyan marker, and disabled controls remain stable.
- **Motion preferences and touch:** Unified timing under the system's reduced-motion preference and shortened toggle transitions. Enlarged mobile settings and code-copy touch targets, with refinements for increased contrast and forced colors.
- **Settings, search, and floating surfaces:** Removed the stepped scan effect from settings search and separated hover from keyboard focus. Reduced duplicate highlights on settings cards and fields and improved descriptions and long directory wrapping. Search inputs use the reading font; menus, tooltips, and dialogs have distinct border and shadow levels. Dark tooltip arrows match their surface color.
- **Tabs and new tabs:** Desktop tabs shrink with available space, active indicators avoid clipping, and long titles leave room for close actions. Pixel Boy adapts to the empty pane's width, with wrapping action labels and scrolling in short windows.
- **Reading and properties:** Softened the reading grid and refined link underlines, text selection, and keyboard focus. Improved long links, inline code, multiline highlights, and property names, long values, and tags in narrow panes.
- **Quotes, code, and tables:** Refined quote and callout fills, nested spacing, and folding feedback. Code-copy controls stay visible while code scrolls independently. Table grids are quieter, column sizing is improved, and row hover remains distinct from native selection.
- **Media and tasks:** Image borders follow the displayed image width. Long attachment names, missing attachments, and embedded-note headings are clearer; scrolling can continue to the page after reaching the end of an embed. Mixed-list indentation and checkbox alignment are more consistent, and completed-task strikethrough no longer affects unfinished subtasks.
- **Outline and link panels:** Fixed heading-fold hover backgrounds covering text and improved long-text readability in narrow outline, backlink, and outgoing-link panels.
- **Bases and Canvas:** Refined database headers, groups, summaries, and empty values. Canvas nodes distinguish selection, focus, and editing, with stable active toolbar feedback.
- **PDF:** Improved toolbar and find-bar access in narrow panes with horizontal scrolling. Fixed the `Aa` find option moving under the pointer on hover.
- **Scrolling and menus:** Distinguished hover from drag feedback on themed scrollbars and pane dividers. Long menu commands can wrap while retaining icon space, and shortcut hints and counters keep stable typography.
- **Print output:** Added clear text and code colors on white paper, improved long code, tables, and embedded content, and retained completed-task states.

Full commit range: [0.9.8 → 0.9.9](https://github.com/CoffeeCheese/obsidian-pixel-theme/compare/0.9.8...0.9.9).

## Compatibility

- Minimum Obsidian version: `1.12.0`, unchanged from the previous release.
- Priority platforms: desktop and iOS.
- Reduced motion follows the system preference. System-native scrollbar appearance remains subject to platform settings.
- No note migration or theme-setting changes are required.
