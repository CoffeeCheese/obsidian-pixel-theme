# Pixel 0.9.3

## Highlights

- **Pixel Boy new tab** turns the empty workspace into Pixel's own handheld console. Its dot-matrix screen, D-pad, A / B buttons, and Select / Start controls form a complete Game Boy-inspired scene while preserving Obsidian's native create, open, and close actions.
- **Native Claudian integration** gives the assistant panel, composer, context chips, and pop-out menus a purpose-built Pixel layout so AI collaboration feels at home in the desktop workspace.
- **One coherent control system** brings preference cards, the circular accent color well, search edge states, inline tags, and the compact status rail into the same pixel-minded visual language.

## Changes

- Added the Pixel Boy empty state with Light, Dark, and narrow-layout calibration while keeping every decorative element inert and keyboard navigation native.
- Reworked Claudian's panel and composer geometry, prevented menu clipping, and refined context chips, root-tab states, and plugin preferences.
- Unified Obsidian preference cards, removed redundant native dividers, and reshaped the accent picker into a clearly bounded circular color well.
- Rebalanced the right dock and global status rail so sync, word-count, backlink, and related telemetry stay compact without crowding note content.
- Refined search inputs across idle, hover, focus, and accessibility states.
- Improved inline tags and split editor hashtag tokens as one continuous capsule across Reading view and Live Preview.
- Refreshed both READMEs with privacy-safe close-up captures and a clearer desktop / iOS-first presentation.
