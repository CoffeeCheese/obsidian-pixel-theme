# Pixel 1.0.0

## Highlights

- **The first stable Pixel release.** The Light and Dark workspace, Pixel Boy new tab, native Obsidian surfaces, and desktop/iOS layouts graduate from the 0.9 series into the stable baseline.
- **Claudian keeps its native content layout.** Fixed the doubled user-message bubble, oversized action rows, and additional composer decoration seen with Claudian 2.2.7. Pixel continues to style the pane chrome and supply inherited theme colors.

## Changes

- Removed Claudian-specific overrides for private message, composer, session, and settings-tab structures. The integration no longer assumes the older textarea editor or outer-message bubble layout.
- Scoped shared control decoration and disabled states away from Claudian's content pane, while preserving Pixel controls on native Obsidian surfaces and view headers.
- Added a live regression check against the installed Claudian DOM in Light and Dark, including focused and unfocused CodeMirror editors, pseudo-elements, message/action geometry, and native button styling. The check preserves the draft and restores theme and focus state.
- Updated CSS contracts, compatibility guidance, and both READMEs to describe the plugin-content boundary. Shared Markdown styling and inherited typography/colors remain intentional.
- Synchronized the theme-store cover with the bilingual README artwork and made Markdown detail galleries open by default.

Full commit range: [0.9.9 → 1.0.0](https://github.com/CoffeeCheese/obsidian-pixel-theme/compare/0.9.9...1.0.0).

## Compatibility

- Minimum Obsidian version: `1.12.0`, unchanged.
- Priority platforms: desktop and iOS.
- Claudian's content boundary was verified with version `2.2.7`; this exception does not automatically apply to every community plugin.
- No note migration or theme-setting changes are required.

## Known issues

- No new blocking issues were found in completed desktop checks and independent code review.
- Third-party plugin content can still inherit Pixel typography, colors, and shared Markdown styles; the compatibility boundary does not reproduce the default theme in full.
