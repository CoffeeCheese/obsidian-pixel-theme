# Pixel 0.9.4

## Highlights

- **Deep Project Manager integration** redesigns the task editor as a calmer, roomier sheet with compact, readable properties and a macOS-inspired Pixel finish.
- **Clearer project and assignee identity** lets long project titles wrap naturally while table assignees use playful emoji avatars beside their complete names.
- **Quieter destructive feedback** gives delete buttons a restrained brick-tinted warning surface with clear hover and press responses, without the previous outer ring or side rail.

## Changes

- Reworked the Project Manager task editor sizing, spacing, title hierarchy, property grid, scrolling, and footer actions.
- Unified task inputs, dropdowns, and date controls with Pixel's search-field edge and interaction model.
- Redesigned the ZenTao creation and closure checkboxes and corrected their vertical alignment with labels.
- Refined the Project Manager assignee column into compact contact plates with emoji avatars and complete names.
- Let long project-detail titles use available toolbar space before wrapping.
- Added a stable two-line title treatment to project dashboard cards so important names are not truncated too early.
- Refined global destructive buttons with a warning tint, hover surface, and pressed response while removing the custom brick focus ring.

## Compatibility

- Minimum Obsidian version: `1.12.0`
- Priority platforms: desktop and iOS
- Project Manager-specific styling primarily targets the desktop plugin interface.
- This visual PATCH release does not change theme settings or data structures.
