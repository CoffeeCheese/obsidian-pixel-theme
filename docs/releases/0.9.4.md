# Pixel 0.9.4

## 更新亮点

- **Project Manager 深度适配**：重新设计任务编辑弹窗，使其拥有更舒展的信息层级、紧凑但易读的属性布局，并与 Pixel 的 macOS 风格视觉保持一致。
- **更清晰的项目与成员信息**：长项目标题支持合理换行；表格中的负责人使用可爱 Emoji 头像与完整姓名展示，不再发生文字截断。
- **更克制的危险操作反馈**：重新设计删除按钮，以柔和砖红背景表达警告语义，并提供清晰的悬停与按压反馈，不再使用突兀的外圈或侧边警告条。

## 更新内容

- 重构 Project Manager 任务编辑弹窗的尺寸、间距、标题、属性区域、底部操作栏和滚动布局。
- 统一任务弹窗中的输入框、下拉框和日期控件，使边框与动态反馈契合 Pixel 搜索框体系。
- 重新设计“创建到禅道”和“关闭禅道任务”复选框，修正与标签文字之间的垂直偏移。
- 优化 Project Manager 表格负责人列，以 Emoji 头像和完整姓名组成简洁的成员信息条。
- 改进项目详情工具栏中的长标题布局，优先利用可用宽度后再换行。
- 项目首页卡片标题支持稳定的两行展示，减少重要项目信息被过早截断。
- 优化全局删除按钮的警告色、悬停背景和按压反馈，并移除不协调的砖红色焦点外圈。

## 兼容性

- 最低 Obsidian 版本：`1.12.0`
- 优先适配平台：桌面端、iOS
- Project Manager 专项样式主要针对桌面端插件界面。
- 本次为视觉修复型 PATCH 版本，不改变主题配置或数据结构。
