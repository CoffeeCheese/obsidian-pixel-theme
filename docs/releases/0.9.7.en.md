# Pixel 0.9.7

## Highlights

- **File-operation targeting is lighter and more precise.** Right-clicking a file other than the open note now uses a compact cyan pixel cursor instead of a heavy green frame, keeping the active-file state visually dominant.
- **Project Manager add actions remain clearly readable.** The “add member” and “add status” buttons now maintain reliable text contrast and use restrained Pixel feedback for hover, press, and keyboard focus.

## Changes

- Reworked temporary file-tree context targets with a quiet surface, hairline edge, and inset cyan rail, while preserving system-color cues in forced-colors mode.
- Fixed Project Manager CTA text becoming unreadable when Pixel's pale settings surface replaced the native CTA background but left its white text unchanged.
- Redesigned the Project Manager add-button rest, hover, pressed, and keyboard-focus states. The cyan rail now grows from the centre only on hover and covers the complete left edge.
- Disabled button transitions under reduced-motion preferences and added navigation and Project Manager settings contracts to prevent visual regressions.

## Compatibility

- Minimum Obsidian version: `1.12.0`
- Priority platforms: desktop and iOS
- These fixes target the desktop file explorer and the Project Manager `1.8.0` settings interface.
- This visual PATCH release does not change theme settings or user data.
