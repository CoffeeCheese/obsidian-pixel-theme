# Pixel 1.0.1

## 更新亮点

- 修复设置中插件开关的滑块超出轨道的问题。
- 修复搜索清除按钮悬停背景覆盖搜索框边线的问题。

## 更新内容

- 将共享控件作用域根移至 `body` 之上，恢复原生界面的选择器匹配，同时保留 Claudian 内容边界，避免插件列表中主题滑块定位与原生位移叠加。
- 移除搜索清除按钮在静止、悬停和按下状态下的整块背景，保留原生图标、点击范围、颜色反馈与键盘焦点提示。
- 新增设置开关与 Chromium 搜索清除交互状态的运行验证，覆盖独立设置窗口及浅色/深色模式。

完整提交范围：[1.0.0 → 1.0.1](https://github.com/CoffeeCheese/obsidian-pixel-theme/compare/1.0.0...1.0.1)。

## 兼容性

- 最低 Obsidian 版本：`1.12.0`，保持不变。
- 继续支持桌面端和 iOS，无需迁移。
- 保留 Claudian 原生内容边界，其运行回归检查通过。

## 已知问题

- 桌面验证和独立审查未发现新增阻塞问题。
- 已在桌面检查移动端 CSS 开关状态；本补丁未单独进行 iOS 真机测试。

## 发布验收

- 自动化测试： Pass
- 桌面人工检查： Pass
- iOS 人工检查： Not required

本次为范围有限的设置控件补丁，已完成桌面视觉和交互检查，未新增移动端布局或兼容性变更，并补充验证移动端 CSS 开关状态。
