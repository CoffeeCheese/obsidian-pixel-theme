# Pixel 0.9.9

## 更新亮点

- **交互反馈更稳定**：完善按钮的悬停、按压与持续激活状态，统一减少动态效果的响应，并修复主操作按钮轮廓重影和 PDF 查找按钮抖动。
- **长文阅读与窄分栏更从容**：改善标签页、属性、引用、代码、表格、嵌入内容与任务列表的排版，完成任务保留删除线，未完成的子任务不受影响。
- **核心界面层级更清楚**：精修设置、搜索、深色浮层、Bases、Canvas 以及打印输出，延续 Pixel 的像素风格与原生操作方式。

## 更新内容

- **按钮与动效**：保留滑动、按压和回弹反馈，取消按压时的文字缩放；区分主操作和危险操作，修复主按钮内侧高光造成的轮廓重影。面板按钮持续激活时显示青色标记，禁用控件保持稳定。
- **动效偏好与触控**：统一系统“减少动态效果”偏好下的时长处理，缩短开关过渡；扩大移动端设置控件和代码复制按钮的触控区域，完善高对比度与强制颜色状态。
- **设置、搜索与浮层**：移除设置搜索的阶梯扫描效果，区分悬停与键盘聚焦；减少设置卡片和输入框的重复高光，改善说明文字与长目录换行。搜索输入使用正文字体，菜单、提示和弹窗采用不同的边框与阴影层级，深色工具提示箭头与浮层底色保持一致。
- **标签页与新标签页**：让桌面标签页随空间收窄，修复活动指示线被裁切的问题，并为长标题保留关闭操作空间。Pixel Boy 根据空白面板宽度调整，支持操作文字换行和矮窗口滚动。
- **正文与属性**：减淡阅读背景网格，改善链接下划线、选中文字和键盘焦点；完善长链接、行内代码、多行高亮，以及窄分栏中的属性名称、长值和标签排版。
- **引用、代码与表格**：调整引用和提示块的底色、嵌套留白与折叠反馈；保持代码复制按钮可见，让代码正文独立滚动。减淡表格网格，改善列宽，并区分行悬停与原生选区。
- **媒体与任务**：让图片边框贴合显示宽度，改善附件长文件名、缺失附件和嵌入笔记的标题层级；嵌入内容滚动到末尾后可继续滚动整页。统一混合列表缩进与复选框对齐，保留完成任务的删除线，并避免划掉未完成的子任务。
- **大纲与链接面板**：修复标题折叠按钮的悬停背景覆盖文字的问题，改善大纲、反向链接和出链面板中的长文本与窄栏阅读。
- **Bases 与 Canvas**：细化数据库表头、分组、汇总及空值的视觉层级；区分白板节点的选中、聚焦与编辑状态，稳定工具栏激活反馈。
- **PDF**：改善窄分栏中的工具栏与查找栏，保持操作可横向访问；修复查找选项 `Aa` 在鼠标移入时发生抖动的问题。
- **滚动与菜单**：区分主题滚动条、分栏分隔线的悬停与拖动状态；让长菜单标题换行时保留图标空间，稳定快捷键提示和计数数字的排版。
- **打印输出**：为导出提供清晰的白底文字与代码配色，改善长代码、表格和嵌入内容的展示，并保留任务完成状态。

完整提交范围：[0.9.8 → 0.9.9](https://github.com/CoffeeCheese/obsidian-pixel-theme/compare/0.9.8...0.9.9)。
