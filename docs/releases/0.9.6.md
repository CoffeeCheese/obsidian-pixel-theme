# Pixel 0.9.6

## 更新亮点

- **Project Manager 标签与 Pixel 主题统一**：需求详情中的标签现在采用紧凑的 Pixel 胶囊样式，文字、圆点与删除操作保持清晰，并消除了原先过高控件和双重边框带来的笨重感。

## 更新内容

- 让 Project Manager 任务编辑器的标签复用 Pixel 主题的背景、边框、文字、圆角与字重变量。
- 将标签高度收敛为紧凑尺寸，并为长标签补充安全的截断显示。
- 重置插件标签删除按钮受到的全局按钮样式，修复其高度、边框、阴影和圆角异常。
- 为标签及删除按钮补充一致的悬停、键盘聚焦和按下反馈。
- 新增 Project Manager 标签样式契约测试，防止后续主题控件规则再次破坏标签布局。

## 兼容性

- 最低 Obsidian 版本：`1.12.0`
- 优先适配平台：桌面端、iOS
- 本次调整针对 Project Manager 的桌面端任务编辑器界面。
- 本次为视觉修复型 PATCH 版本，不改变主题配置或用户数据。
