# Pixel 0.9.2

## Highlights

- Reworked the Preferences interaction hierarchy so search fields, core-plugin actions, toggles, and sidebar navigation share stable pixel geometry, alignment, and feedback timing.
- Fixed the macOS title bar, ribbon, and rounded-window junctions to keep the top workspace visually continuous and free of dark seams.
- Refined core-plugin search with a restrained scan-rail response on focus, no idle decorative artifact, and full reduced-motion support.

## Changes

- Reduced Preferences search fields to one quiet hairline edge; focus now uses an inset cyan state while redundant outer frames and the idle left rail are removed.
- Unified the core-plugin settings, secondary actions, and enable toggles, fixing misaligned controls and switch thumbs that escaped their tracks while retaining keyboard focus and pressed feedback.
- Added a stable pale-cyan hover slot to Preferences navigation without shifting rows; the current item keeps a stronger selected state.
- Refined macOS top-control background mapping, dark-mode corners, and the ribbon seam to remove abrupt color blocks around the window edge.
- Removed the 1 MiB total generated-CSS build gate while retaining the 0.9 MiB embedded-font budget, self-contained asset validation, and release-asset checks.

## Compatibility

- Minimum Obsidian version: `1.12.0`
- Verified platform: desktop; iOS carries forward the `0.9.1` validation result
- Unverified platform: Android
- Community plugins: plugins using official Obsidian CSS variables should inherit the theme naturally, but individual plugin compatibility is not guaranteed.

## Known issues

- Android has not completed physical-device validation and remains outside the current support claim.
- `0.9.x` remains a public beta series; visual details and surface coverage will continue to evolve from community feedback.
