# Pixel 0.9.0

## Highlights

- Pixel enters the Obsidian theme community as a public beta covering Light and Dark workflows on desktop and iOS.
- A reproducible, unprefixed SemVer tag workflow allows future versions to be discovered and updated directly by Obsidian.
- Markdown, navigation, properties, Bases, Canvas, Graph, and PDF share one paper-and-pixel visual language.

## Changes

- Completed the continuous desktop workspace, native dual-drawer iOS layout, and keyboard, touch, and zoom adaptations.
- Embedded Fusion Pixel and JetBrains Mono so the runtime theme requests no remote fonts or images.
- Added Light, Dark, reduced-motion, forced-color, and increased-contrast adaptations.
- Limited each Release to `theme.css` and `manifest.json`, with GitHub build provenance attestations.

## Compatibility

- Minimum Obsidian version: `1.12.0`
- Release validation scope: desktop and iOS
- Unverified platform: Android
- Community plugins: plugins using official Obsidian CSS variables should inherit the theme naturally, but individual plugin compatibility is not guaranteed.

## Known issues

- Android has not completed physical-device validation and is outside the current support claim.
- `0.9.x` is a public beta series; visual details and surface coverage will continue to evolve from feedback.
