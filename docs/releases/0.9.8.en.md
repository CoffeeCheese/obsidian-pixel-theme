# Pixel 0.9.8

## Highlights

- **Markdown details are more stable and easier to identify.** Image scrolling, task completion feedback, and fenced-code identity are more consistent, with a new banner format for prominent page imagery.
- **Input and documentation details are clearer.** Templater date fields use a lighter, more explicit interaction boundary, while the README makes release context, installation guidance, and detailed sections easier to read directly.

## Changes

- Fixed large blank areas that could appear when rapidly scrolling long Live Preview documents containing aligned images, without changing image sizing or alignment.
- Added the `pixel-banner` image format for full-width cropped banners through `![[image.png|pixel-banner]]`.
- Refined task-checkbox completion and press feedback without changing checkbox dimensions or task-row layout, while respecting reduced-motion preferences.
- Added a cyan Pixel status header to fenced code blocks. Live Preview shows the detected language, Reading shows a consistent `CODE` label, and the native copy button remains available.
- Refined Templater date-field rest, hover, focus, reduced-motion, and forced-colors states.
- Reorganized the README's recent-release summary and installation guidance, and expanded detailed sections by default.

## Compatibility

- Minimum Obsidian version: `1.12.0`
- Priority platforms: desktop and iOS
- This release refines Markdown, Templater, and documentation details without changing theme settings or user data.

- No known issues.
