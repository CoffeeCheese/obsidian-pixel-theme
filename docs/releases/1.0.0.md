# Pixel 1.0.0

## 更新亮点

- **Pixel 首个稳定版本。** 深浅色工作区、Pixel Boy 新标签页、Obsidian 原生界面，以及桌面端和 iOS 布局，从 0.9 系列进入稳定版本基线。
- **Claudian 保留原生内容布局。** 修复 Claudian 2.2.7 的双层用户消息气泡、操作栏高度异常和输入区额外装饰。面板外框和继承的主题颜色仍保持 Pixel 风格。

## 更新内容

- 移除针对 Claudian 私有消息、输入区、会话和设置标签结构的样式覆盖，不再依赖旧版 textarea 编辑器或外层消息气泡结构。
- 将共享控件装饰与禁用状态样式限制在 Claudian 内容面板之外，保留 Obsidian 原生界面和视图标题栏的 Pixel 控件样式。
- 新增基于实际安装的 Claudian DOM 的深浅色回归检查，覆盖 CodeMirror 聚焦与未聚焦状态、伪元素、消息与操作栏尺寸，以及原生按钮样式。检查会保留草稿并恢复主题和焦点状态。
- 更新 CSS 契约、兼容性说明和双语 README，明确插件内容样式边界；共享 Markdown 样式及继承的字体和配色仍予保留。
- 同步主题商店封面与双语 README 主图，并将 Markdown 细节图库调整为默认展开。

完整提交范围：[0.9.9 → 1.0.0](https://github.com/CoffeeCheese/obsidian-pixel-theme/compare/0.9.9...1.0.0)。

## 兼容性

- 最低 Obsidian 版本：`1.12.0`，保持不变。
- 优先适配平台：桌面端、iOS。
- Claudian 内容边界已使用 `2.2.7` 验证；该例外不会自动应用到所有社区插件。
- 无需迁移笔记或调整主题设置。

## 已知问题

- 已完成的桌面检查与独立代码审查未发现新的阻断问题。
- 第三方插件内容仍可继承 Pixel 字体、配色和共享 Markdown 样式；兼容边界不等同于完全恢复默认主题。

- 桌面人工检查：Pass
